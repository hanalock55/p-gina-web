¿Qué son las Sentencias de Control en Java?

Son estructuras que permiten controlar el flujo de ejecución del código según condiciones específicas. Estas sentencias son esenciales para tomar decisiones, repetir acciones y manejar el comportamiento lógico de las aplicaciones.

Sentencia If / Else

Ejecuta un bloque de código si una condición es verdadera, y otro bloque si no lo es. 

if (edad >= 18) {
  System.out.println("Eres mayor de edad");
} else {
  System.out.println("Eres menor de edad");
}

Sentencia Switch

Elige entre múltiples bloques de código según el valor de una variable. 

switch(dia) {
  case 1:
    System.out.println("Lunes");
    break;
  case 2:
    System.out.println("Martes");
    break;
  default:
    System.out.println("Otro día");
}

Bucles: For, While y Do-While

Repite una acción mientras se cumpla una condición. 

for (int i = 0; i < 5; i++) {
  System.out.println(i);
}

int i = 0;
while (i < 5) {
  System.out.println(i);
  i++;
}

i = 0;
do {
  System.out.println(i);
  i++;
} while (i < 5);
